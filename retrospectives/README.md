# retrospectives/ — Per-Pursuit Post-Mortems

Drop post-proposal retrospectives here, one file per pursuit. Format suggestion:

```text
retrospectives/
├── <rfp-slug>_postmortem.md       # main retro doc
└── <rfp-slug>_notes.md            # optional field notes
```

This folder exists as an empty scaffold in the engine template. In a
scaffolded proposal repo, it holds only that pursuit's retrospective content.

Engine-internal retrospectives (the post-mortems that seeded this template's
backlog) live in `docs/retrospectives/` and are not scaffolded into child
proposal repos.
