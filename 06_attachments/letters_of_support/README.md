# Letters of Support / Teaming Letters

Place signed letters of support, teaming agreements (non-confidential portions), and partner commitment letters here.

> ⚠️ PDF files in this folder are gitignored by default.  
> To track a specific letter: `!06_attachments/letters_of_support/letter_partner_name.pdf`

## Expected Files

| File | From | Purpose | Received? |
|---|---|---|---|
| `letter_PLACEHOLDER_partner.pdf` | `PLACEHOLDER: Partner Firm` | Teaming commitment | ☐ |
| `letter_PLACEHOLDER_reference.pdf` | `PLACEHOLDER: Reference Client` | Endorsement / reference letter | ☐ |

## Checklist Before Submission

- [ ] All letters are on official letterhead
- [ ] All letters are signed (wet or electronic signature)
- [ ] Letters reference the specific RFP number and title
- [ ] Dates on letters are current (within 12 months, or as required by RFP)
