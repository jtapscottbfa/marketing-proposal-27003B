# Data Attachments

Place supporting data files here (pricing schedules, staffing matrices, etc.).

> ⚠️ `.xlsx` and `.csv` files are gitignored by default to avoid committing sensitive pricing data.  
> To track a specific file in Git, explicitly un-ignore it: add `!06_attachments/data/my_file.xlsx` to `.gitignore`.

> Files here are assembled separately from the narrative build. Depending on pursuit needs, they may be folded into the compiled document or submitted as standalone attachments/appendices.
