# Brand Guidelines

Define your firm's brand tokens here. These values are used by the `scripts/publish/` tools
and the `templates/docx_reference/` reference.docx to ensure consistent document styling.

## Colour Palette

| Role | Name | Hex | Usage |
|---|---|---|---|
| Primary | Deep Burgundy | `#561A1A` | Headings (H1–H5), table headers, footer firm name |
| Primary Dark | Dark Burgundy | `#4D1C1B` | Footer firm name accent |
| Subtext | Dark Grey | `#404040` | Secondary header text, captions |
| Table Alt Row | Burgundy Tint | `#F5EDED` | Alternating table rows |
| Table Border | Muted Burgundy | `#C8A0A0` | Table cell borders |
| Rule / Divider | Medium Grey | `#A6A6A6` | Footer top rule, header bottom rule |
| Body text | Near Black | `#000000` | All body copy |
| White | White | `#FFFFFF` | Table header text |

## Typography

| Element | Font | Size | Weight |
|---|---|---|---|
| Heading 1 | Source Sans Pro | 16pt | Bold |
| Heading 2 | Source Sans Pro | 13pt | Bold |
| Heading 3 | Source Sans Pro | 11pt | Bold |
| Heading 4 | Source Sans Pro | 11pt | Bold Italic |
| Body | Calibri | 11pt | Regular |
| Caption | Calibri | 9pt | Italic |
| Header / Footer | Source Sans Pro | 8pt | Regular |

## Page Layout (US Letter)

- **Margins:** 1 inch all sides (or as required by RFP)
- **Header:** Firm name (left) | RFP number (right)
- **Footer:** Proposal title (left) | Page number (right) | PROPRIETARY notice (centre)
- **Page size:** 8.5" × 11" (12240 × 15840 DXA)

> These values are applied in `templates/docx_reference/reference.docx`.
> To update styles, open reference.docx in Word, modify the named styles, and save.
