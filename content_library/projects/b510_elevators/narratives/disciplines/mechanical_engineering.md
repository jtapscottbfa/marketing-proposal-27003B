The mechanical scope on this project centered on environmental conditioning of two overhead elevator machine rooms in Building 510 at Norfolk Naval Shipyard. Each machine room required replacement of the existing steam heating system with a new ductless split air-conditioning system — one outdoor condensing unit and one wall-mounted fan coil per room — designed to maintain 72°F/50% relative humidity for cooling and 50°F for heating. The estimated heat gain for each machine room was 20,265 BTU/hr, driven primarily by the traction machine motor loads during elevator run cycles. Existing steam radiators and steam/condensate piping were demolished and removed to a point outside each machine room.

Elevators #63 and #67 share a single overhead machine room (approximately 24'-0" × 24'-10"), served by one ductless system. Elevator #64 occupies a separate machine room (approximately 17'-6" × 22'-9"), also served by a dedicated ductless unit. Each system was sized individually for its respective machine room heat load.

DDC controls for the new HVAC systems were required per the Statement of A-E Services, with each machine room's system connecting to NNSY's base-wide building automation and control network. The DDC integration was scoped to meet UFC 4-010-06 cybersecurity requirements for facility-related control systems on the naval installation.
