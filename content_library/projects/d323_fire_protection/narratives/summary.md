This Design-Build project modernizes the fire protection system in the basement server room (Room 003) of Building D323 (Farragut Hall) at Naval Support Facility Indian Head, Maryland — a 32,645 SF Naval Operations Center and Information Services facility for Naval Surface Warfare Center Indian Head Division (NSWC IHD), constructed in 1941. The active project scope is approximately 1,980 SF, covering the raised-floor server room (Room 003, 1,817 SF) and an adjacent corridor segment (H002, 163 SF) used for pressure relief.

The principal scope is demolition of the end-of-life Halon 1301 suppression system — 1982-vintage Kidde KPH-60 cylinders and a Fire Lite Sensiscan 1000 control panel — and replacement with a pre-engineered NFPA 2001-compliant clean agent system (inert gas or Novec 1230 at 30% design concentration, approximately 39 cylinders total). Fire detection upgrades include a new Fire Alarm Releasing Control Panel with Very Early Warning Smoke Detection (VEWSD) under the raised floor, above-floor detectors, Emergency Power Off (EPO) supervision, relay interfaces to CRAC units, and integration with the building's main fire alarm system and the Emergency Operations Center in Building D327 via AES radio mesh network. A companion exhaust system — inline fans, motorized dampers, ductwork, and underfloor grilles — provides post-discharge agent clearing to allow fire services safe re-entry. Electrical scope supports exhaust system power, control wiring, and fire alarm integration.

Additional project constraints include hazmat coordination (ACM and LBP present throughout the 1941 host building), fan pressurization leak testing per NFPA 2001, and DoD ozone-depleting substance procedures for halon cylinder disposition. The project is executed under ECMP 1204 of the Kekolu Design-Build Job Order Contract at NSF Indian Head.
