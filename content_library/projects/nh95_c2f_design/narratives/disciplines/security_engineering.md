# Security Engineering — C2F NH95 Renovations

The security engineering scope for the C2F NH95 Renovations addresses the physical and electronic security requirements of an active US Second Fleet (C2F) command facility at Naval Station Norfolk, designed to meet NAVFAC controlled-area standards and DoD security requirements for military operational spaces.

An Electronic Security System (ESS) is designed throughout the renovation area, comprising perimeter sensors, closed-circuit television (CCTV) coverage at the primary entrance, card reader with keypad access control at controlled access points, and a Panel Control Unit (PCU) with backup power to ensure continued security operations during power interruptions. The ESS design follows NAVFAC ESS standards applicable to military installation facilities.

Controlled area design requirements govern the physical construction of the project: the facility is a restricted military area permitting no alien personnel on site during construction or occupancy, a constraint that drives both the design approach and the construction contract requirements. The ICD 705 Type A wall construction for the EF/POP room — designed in coordination with the telecommunications discipline — represents the highest security construction standard on the project, providing electromagnetic and physical security separation for the classified communications environment.

Security engineering on this project spans both physical access control and classified space construction, reflecting the dual nature of security requirements for a standing operational fleet command: perimeter control for the general facility and a purpose-built secure enclosure for the command's classified communications infrastructure.
