Security engineering for the Building 1470 2nd Floor Vault Expansion at Naval Support Facility Dahlgren, Virginia encompassed design of the Electronic Security System (ESS) and SCIF construction compliance for the new approximately 4,200-square-foot second-floor classified addition. The security scope addresses both the physical construction requirements of ICD/ICS 705 and the electronic access control and intrusion detection systems that govern entry into the facility's classified workspaces.

The Electronic Security System is based on the Lenel access control platform, consistent with the existing facility infrastructure. Thirteen HID pivCLASS RPK-40-H card readers with integrated keypads are installed at each workroom entrance, providing two-factor (card + PIN) access control at every secure door. Thirteen HES 4500C electric strikes secure controlled doors, and three Magnasphere balanced magnetic switches (BMS) monitor emergency and primary entry doors. Seventeen Bosch DS938Z PIR motion detectors provide interior intrusion detection coverage throughout the addition. Two Lenel LNL-1100 Intelligent Controller Modules (ICM) and six LNL-1320 Door Reader Interface modules manage the access control points, supported by two Altronix power supplies. Blue strobe lights at each workroom door provide visual controlled-access status indication. All new ESS equipment connects to the existing Lenel controller in Room 1203 via the NDW 3SP network.

SCIF construction per ICD/ICS 705 Wall A specifications — including STC 50/1-hour rated assemblies, multi-layer Type X gypsum board at secure perimeters, conduit grounding at SCIF wall penetrations, and elimination of exterior glazing — is coordinated across all disciplines and documented in detailed penetration and grounding details that form a core part of the construction document package.
