Telecommunications engineering for the Building 1470 2nd Floor Vault Expansion at Naval Support Facility Dahlgren, Virginia provided structured cabling and low-voltage infrastructure design for the new approximately 4,200-square-foot second-floor SCIF addition. The telecommunications scope is distinguished by the requirement to support five physically separate network types within a single classified facility, each with distinct security classification and physical separation requirements.

The five networks — classified NMCI (cNMCI), unclassified NMCI (uNMCI), classified RDT&E (cRDT&E), unclassified RDT&E (uRDT&E), CNET, and JWICS — are each installed with color-coded CAT6A F/UTP cabling and individually identified Panduit Mini-Com faceplates and jacks to ensure unambiguous network identification at every outlet. Basket-type cable tray in the corridor provides organized multi-network routing while maintaining clear physical separation between networks of different classification levels.

A new server room (Room 206) is designed per EIA/TIA 569-B and serves as the second-floor telecommunications hub. The room houses separate wall-mount cabinets for each major network: a Liebert cabinet for CNET, a Holocom cabinet for NMCI, and a Hubbell QuadCab for JWICS. A new 8-inch EMT conduit run connects the new server room to the existing server room (1302O), mechanical/comms room (1311), and fiber communications room (1705). ISP fiber (24-strand single-mode OS2) runs from Comm Room 1705 to the new uNMCI cabinet; a 2-fiber JWICS circuit routes from Room 1705 to the new JWICS cabinet. A Telecommunications Main Grounding Busbar (TMGB) is installed in the server room. RCDD-approved design was required for all telecommunications work.
