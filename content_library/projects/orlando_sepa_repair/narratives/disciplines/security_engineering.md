Security engineering was the primary design discipline on the NOSC Orlando SEPA Repairs project, encompassing the full electronic security system (ESS) design and specification of the physical barrier and security hardware systems. The project addressed ATFP vulnerabilities identified in the Navy's programmatic security evaluation of NOSC facilities following the 2015 Chattanooga attack.

The ESS comprised three integrated subsystems. The access control system (ACS) was built on the Hirsch/Identiv DIGI*TRAC Model 8 controller platform running the Velocity software system, with SNIB3 network interface boards and RREB remote reader expansion boards. CAC-compatible scramble keypad readers (uTrust TS Government) were specified and installed at all exterior access doors, at both vehicle gates, and at both pedestrian turnstile positions, providing credential-based access control across the full facility perimeter. The video surveillance system (VSS) deployed five PTZ IP dome cameras on the building perimeter and one fixed IP dome camera at the quarterdeck exterior, with all cameras connected to a new 16-channel hybrid DVR/NVR (Speco D16HT, 8TB). The security communication system (SCS) provided Aiphone GT multi-tenant intercom and speakerphone stations at all gate and turnstile positions, linking to seven monitoring locations distributed across the Wilson, Taft, and Smedley Buildings and the facility supply bay.

All three ESS subsystems were integrated through the security system workstation in the Unit Commons (Room W205A), with headend equipment housed in a dedicated rack in Room S109 Telecom. The security engineering design also specified K-rated vehicle barrier systems — cantilevered sliding gates and anti-ram perimeter cable — in coordination with the civil engineering discipline, and addressed security hardware including fragmentation retention film and shelter-in-place door hardware in coordination with the architecture discipline.
