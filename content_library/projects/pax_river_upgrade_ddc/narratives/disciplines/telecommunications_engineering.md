# Telecommunications Engineering — B2185, B2187, B2855 Replace DDC Controls, NAS Patuxent River

Telecommunications engineering on this project addressed the network infrastructure and integration requirements of the replacement DDC systems, bridging the building-level controls networks to the base-wide communications infrastructure at NAS Patuxent River.

The DDC network architecture specified BACnet/IP as the backbone protocol with MS/TP field networks at the device level, per ASHRAE Standard 135 and UFC 3-410-02. Telecommunications engineering was responsible for the design of this network topology — routing, segmentation, and physical infrastructure — across all three buildings. In Buildings 2187 and 2855, the network termination interface was the government-furnished Facility Point of Connection (FPOC) panel, which provided the physical and logical handoff point between the building's BACnet/IP infrastructure and the base-wide UMCS network managed by a separate government contractor.

Integration with the base-wide Niagara 4.x UMCS was a primary deliverable. The project team was responsible for providing complete DDC system information — point lists, network addressing, device configurations — to support government personnel completing the UMCS integration on the base side. Coordination of this interface required careful documentation of every connected data point and network device.

Cybersecurity requirements for the facility-related control system network — governed by UFC 4-010-06, UFGS 25 05 11, and NIST 800-82 — drove significant telecommunications scope. Requirements included IEEE 802.1x network access control, PIV credential integration, physical security of network components, and prohibition of wireless connectivity except where specifically approved. These requirements treated the DDC/BAS network as an OT (Operational Technology) network subject to DoD Risk Management Framework controls, with telecommunications engineering coordinating compliance across the network design.
