Fire protection engineering services encompassed modifications to the existing wet pipe sprinkler system and upgrades to the fire alarm system for both elevator shafts and machine rooms in Building 276 at the Norfolk Naval Shipyard, including elevator controller interfaces required for Firefighters' Emergency Operation (FEO).

For each elevator, new sprinkler piping was extended from the fourth-floor level to the machine room, complete with a supervised shut-off valve, check valve, waterflow switch, and test and drain valve — providing independent, supervised fire suppression coverage for the machine room consistent with current code requirements for elevator machine rooms. Elevator pit and hoistway sprinkler coverage was coordinated with the new elevator equipment layouts and clearance requirements. Waterflow switches were wired to activate shunt trip breakers on the elevator power feeds, automatically disconnecting elevator power upon sprinkler actuation as required by code for elevator installations where the machine room is above the lowest landing served.

The existing fire alarm system in Building 276 was modified to interface with each elevator controller for FEO, enabling the required Phase I recall and Phase II firefighter override operating sequences during a fire event. Smoke detectors were provided at all elevator landings and in each machine room to initiate the recall sequence, integrated with the existing NNSY Building 276 fire alarm system infrastructure.
