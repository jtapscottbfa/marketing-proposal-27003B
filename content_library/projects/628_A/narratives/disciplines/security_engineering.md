# Security Engineering — Building 6-28A Title II Services

Security engineering on the Building 6-28A Dynamometer Building project was scoped as intrusion alarm rough-in design, with BFA serving as engineer of record for this discipline as part of the comprehensive Title II services package.

The intrusion alarm scope was newly added to the design package (it did not exist in the 2017 design) and required BFA to design conduit and pull-string rough-in infrastructure for a future intrusion detection system across all personnel doors, overhead/canister doors, and interior PIR sensor locations. The design specified ½-inch EMT conduit and single-gang electrical boxes configured as homerun circuits to a plenum mounted above Vestibule 100 (Room 100). Drop locations included: conduit at each personnel door at the top lock-stile side and at 5 feet above finished floor on the lock-stile side; keypad locations above light switches; overhead and canister door lower sill locations (both sides); four evenly spaced PIR drops in the roof line of the Machine Shop (Room 110); and two evenly spaced PIR drops in the roof line of the Vehicle Maintenance Area (Room 120).

This scope reflects HPDTA's status as a DoD installation with strict physical security requirements — including US Citizenship requirements for all contractor personnel, no unauthorized electronic devices on base, and Base Security review of any access control or radio equipment requests. The intrusion alarm rough-in provides the infrastructure for a government-installed and -operated detection system, while the design drawings and specifications ensure correct conduit sizing, routing, and termination point coordination with the communications outbuilding infrastructure.
